# Code of Conduct

Dürbün follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work.
Harassment, insults, and personal or political attacks are not accepted in issues, pull requests,
discussions or any other project space.

## Reporting

- **Abuse on GitHub:** use GitHub's **Report content** option in the menu of the comment, issue, pull
  request or discussion. GitHub's staff review these reports.
- **To reach the maintainer privately:** open a private report with the repository's
  [vulnerability report form](https://github.com/mykynk/durbun/security/advisories/new) and say in the title
  that it is a Code of Conduct report. The form is meant for security problems, but it is the project's private
  channel today: only you and the maintainer, [@mykynk](https://github.com/mykynk), can read the report.

Reports are handled confidentially. The maintainer may edit or remove contributions and block participants who
do not follow this code.
